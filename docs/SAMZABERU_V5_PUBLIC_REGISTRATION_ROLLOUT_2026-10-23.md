## Важные ограничения

1. **Скрипт не запущен в production на момент записи этой документации.** Не объявлять endpoint доступным разработчику до фактического положительного `FINAL_STATUS=PASS` и проверки, что это не только `ALREADY_APPLIED=YES`.
2. Скрипт рассчитан на **исходную** уже исследованную OFF-only release `0caa0248...`. Если уже применён предыдущий legal-upgrader или baseline успел измениться, script безопасно откажет; нельзя вычищать чужие release или произвольно обходить guard.
3. По явной воле пользователя V4 сохраняется **только временно** до полной миграции потребителей; V5 — один целевой API. Но этот выпуск публикует лишь read-only registration/legal, не выдает AUTH/JWT, не превращает GET cart в production и не переименовывает физический сайт.
4. CI `bash -n`, wrong-host refusal и остальные source-only PHP tests не заменяют реальный production HTTP E2E. Все текущие мобильные и серверные клиенты должны по-прежнему получать работу V4 до отдельного cutover.

## Блокер развёртывания разрешается через действующую двухфайловую схему

Документированный production checkpoint §1 уже показывает, что 23 октября через отдельный принятый deploy был установлен **другой публичный V5 bootstrap**: `api/v5/router.php → local/samzaberu-v5/api/v5/site.php → local router`; его checkpoint `/root/ev-v5-checkpoints/v5-off-deployed-20261023.npcVIr3E`. Скрипт этой страницы всё ещё ожидает старый релизный bootstrap из `installed.sha256` и поэтому **не совместим с текущей установленной схемой**. Сначала нужно проверить текущий SHA256 `f502ae47...` по checkpoint и неизменность `local/` файлов. До этого НЕ восстанавливать старый shim, НЕ пересоздавать manifest, НЕ обходить guards. При реализации нового V5-only установщика сохранять фактическую двухфайловую архитектуру и её rollback. Отдельно: локальный curl с `evrasia` на публичный `evrasia.rest` ранее дал RC=7/HTTP 000, возможен NAT hairpin; отсутствие само-подключения не доказывает недоступность для мобильных пользователей. Нужна origin-проверка и независимый внешний тест; не использовать локальный hairpin как единственный критерий отката.
