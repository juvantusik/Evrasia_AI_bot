# Evrasia AI Bot v1.6.9 — web directory preview

This branch contains a safe interactive preview of the planned corporate web directory.

## Preview behavior

- URL: `/directory`
- 62 restaurant records are seeded from the secretary workbook without importing its phone columns.
- Corporate phone values are loaded read-only from PostgreSQL `corporate_phone_directory` through `/api/directory/phones`.
- Restaurant edits, OU moves and personal-number edits are browser-memory only and are lost on refresh.
- Excel export is intentionally disabled in this preview.
- No new database migration is included in the preview.
- Production v1.6 must not be replaced by this branch without explicit approval.

Full specification: Confluence page 3637249 / Jira KAN-65 / GitHub issue #18.
