# Evrasia AI Bot v1.6.9 — web directory preview

This branch contains the isolated corporate web directory. It does not start Telegram polling, Bitrix or SamZaberu routes.

## Preview behavior

- URL: `/directory`
- PostgreSQL is the runtime master database for phones, restaurants and audit history.
- On first start, 62 restaurant records are inserted into `corporate_directory_restaurants`; existing rows and web edits are never overwritten by the seed.
- Phone CRUD uses the existing `corporate_phone_directory` table shared with Telegram.
- Restaurant edits, OU moves and personal-number settings are persisted in PostgreSQL and survive browser refreshes and container restarts.
- Every web write creates an audit record with the action, actor, before-state and after-state.
- Write operations require `DIRECTORY_WEB_WRITE_TOKEN`; read operations remain available to the preview.
- Excel export is intentionally disabled at this stage.
- Production v1.65 must not be replaced by this branch without explicit approval.

Full specification: Confluence page 3637249 / Jira KAN-65 / GitHub issue #18.
