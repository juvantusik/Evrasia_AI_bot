# СамЗаберу V5 — прежний план отдельного стенда ЗАМЕНЁН

**15 октября 2026: отдельная VM/новый сервер отменены пользователем как обязательное условие.** V5 делаем параллельно V4 на существующем Bitrix-сервере. Не запрашивать новую VM, адрес гипервизора или вторую копию сайта для продолжения.

## Было → стало → почему

Было: этот документ требовал отдельную VM, независимый DB instance и запрещал рассматривать размещение на `evrasia`/`eur-bot-01`.

Стало: `/api/v5/…` добавляется рядом с `/api/v4/…` на существующем Bitrix `evrasia`; аккаунты и бизнес-данные общие, служебные V5 tables/keys/code/config/routes отдельные. Дополнительные VM/контейнерная копия всего сайта/второй MySQL не обязательны. Бот на `eur-bot-01` не переносится.

Причина: пользователь явно отверг отдельную инфраструктуру. Предыдущий план представлял выбранный способ изоляции как безусловное техническое требование, что не соответствует принятой целевой архитектуре.

Полный прежний план сохранён в Git commit `91b7f9d5ce73aa672344d81c95b6427053735df8` по этому же пути. Его требования выделения VM больше не действуют. Исторические isolation/fault-test runbooks не определяют текущий NEXT.

## Актуальная работа

Читать `SAMZABERU_V5_START_HERE_2026-10-15.md`, `SAMZABERU_V5_NEXT_CHAT_CHECKPOINT_2026-10-15.md` и решения R7/R8 в `SAMZABERU_V5_INTEGRATION_DECISIONS_2026-10-15.md`. Issue76 теперь о параллельном подключении V5 к существующему сайту. PHP entry реализован в feature с выключенным состоянием по умолчанию; native factory/site installation ещё не выполнены.

## Сохранённые ограничения

Параллельное размещение не означает, что можно экспериментировать с рабочими аккаунтами/таблицами. Только целевой approved deployment/migration plan, backup/verify/rollback, ограниченная приёмка на согласованных тестовых аккаунтах, без незапрошенных реальных SMS/платежей. Не отключать CI-only guards и не запускать synthetic CREATE/ALTER/fault/concurrency scripts в production DB. Native event/replay/epoch guarantees остаются обязательными и не заменяются конфигурационным true.
